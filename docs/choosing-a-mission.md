# Choosing a mission

A **mission** is a lesson plan; a **game** is a class playing that plan. A mission has **chapters** (lessons or sessions), each containing **tasks**. Students share the plaza but have private roles, clues and progress in their **Journal**.

These are the five original mission variants found in the classroom copy. Missions are editable data, so use the Studio's current counts and comparisons when reviewing an edited copy.

| Mission | Included experience | Main difference |
| --- | --- | --- |
| The Haunted Castanyada | Three chapters; nine main questions and six bonus tasks. | The shortest mystery. No quest-board activities. |
| Castanyada: Side Mysteries | The same three-chapter main mystery, with two partner quests in chapter one. | An early expansion of the original. |
| The Haunted Castanyada: Five Chapters | Five chapters; seventeen main tasks, six bonus tasks and ten partner quests. | Extends the story through the missing festival plan and haunted celebration. |
| Castanyada: Witness Investigations | The five-chapter story and its ten partner quests. | All seventeen main tasks require witness exchanges with classmates before answering; the thief question requires two witnesses. More talking between students. |
| Plaza Free Play: Side Quests | Eight sessions, each with one written check-in; no board quests included. | A starter for activities the teacher selects and adds. It is not a ready-made mystery. |

For a simpler library, Five Chapters is a useful main choice. Keep the original if you also want a shorter story. Side Mysteries overlaps with both. Witness Investigations is an alternative when you specifically want mandatory evidence exchanges. Free Play serves a different purpose and needs preparation.

## Where the quest board is

The quest board is a section of the student's **Journal**, with an **Accept quest** button for each optional activity. It is already part of the game. Some activities wait for main tasks to finish, a suitable partner, or teacher release.

For Free Play, first start the mission in a game. Then open **Side quest library**, select activities, choose **Review and add to the game**, and **Release to students**. Students will see the activities in their Journals. Repeat for each new session. The library release affects the currently running game, not all future copies of the mission.

The Free Play ending “Great start! Keep choosing quests…” is a student message written on the assumption that you supplied activities. The Studio now flags this gap and separates student story text from teacher instructions.

## Removing a mission

Use **Delete** on its library card or **Delete mission** in the editor, then **Move to Trash**. This removes it from the choices for new games while preserving games already in progress. **Restore mission** brings it back. If there are unsaved edits, save or download them first; Trash retains the saved version.
