# Six quick warm-ups

Each activity takes about 3–5 minutes. The goal is a short chat with classmates. All facts and identities are pretend. These activities contain no mystery answers and also work without Season 3.

| File | Select this type | Students practise |
| --- | --- | --- |
| `01-bag-detectives.json` | Find someone who… | “Do you have a key?” / “Yes, I do.” |
| `02-wild-weekend.json` | Find someone who… | “Did you visit the moon?” / “Yes, I did.” |
| `03-mystery-objects.json` | Who am I? | “Can I wear you?” / “No.” |
| `04-secret-animals.json` | Who am I? | “Can you fly?” / “No.” |
| `05-perfect-pairs.json` | Find your pair | “What do you have?” / “I have a lock.” |
| `06-problem-solvers.json` | Find your pair | “What do you need?” / “I need a charger.” |

Open the **Warm-up editor** from Teacher controls. Select the matching type, choose **Import JSON**, review the preview, apply it and **Save warm-up**. Then start that type from Teacher controls. Import each JSON separately; importing the mission ZIP does not install warm-ups.

The editor saves one configuration per type. Importing another activity of the same type replaces its saved configuration when you save. Export your current configuration first if you want to keep it. A running round keeps its original content; start or restart to use the new activity.

For facts and pairs, students type a **classmate’s name**. For identities, they ask the **named classmate** and type the **secret object or animal**. Model one exchange before starting. Use the app’s assigned targets; an odd-sized pairs group uses its existing three-person fallback.

Picture symbols support selected object cards. Every symbol also has an English label, so students do not need to identify an emoji. The current warm-up format does not support attached image cards; the campaign’s private picture clues are separate.

Suggested lesson order: Bag Detectives before chapter 1; Mystery Objects before chapter 2; Problem Solvers before chapter 3; Secret Animals before chapter 4. Use Wild Weekend and Find My Other Half for replay lessons or other classes.

After a match, invite one extra spoken line: “Where did you get it?”, “What happened next?”, or “Why do these go together?” This is a teacher-led extension, not an extra software requirement. Keep the main on-screen instructions short.
